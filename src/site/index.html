HOW IT WORKS

  • Every service is checked every 5 minutes. A Cloudflare timer starts each run; GitHub's own schedule is a slower backup.
  • Vendor status monitors read the vendor's official status feed. Accurate, but vendors often post 15 to 45 minutes late.
  • Direct probes load a real login page or API and time it. These usually catch a problem first. A probe only counts as failed if it fails twice, 15 seconds apart.
  • The bars on each monitor are the last 24 hours, one per hour, oldest on the left. Hover a bar for details. Click a monitor to open that vendor's status page.
  • Alerts go to phone push only when something changes: a new problem, a worse problem, or a recovery.
  • Can't check means the status source couldn't be read 3 runs in a row. Not set up means the check still needs credentials.
  • The guards are decoration. The data on the monitors is real.
